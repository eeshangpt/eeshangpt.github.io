How I check my own claims

For project figures I can say only so much here. For my own claims I can show all the working, so I test them in public. Three claims tested so far: one was dropped and two need more work. Nothing has met the bar I set for scaling it up yet.

For the finished ones, what counts as a pass or a fail was written down before the results existed, and each write-up says where its findings stop holding. The numbers are on the linked pages.

    Can a fast small model take the easy cases and pass on the hard ones?

    Same write-up, second half

What makes an evaluation trustworthy

Trust in an evaluation starts with the choice of metrics and how they are calculated. Then comes the comparison: setting a model with no retrieval against a RAG-enabled chatbot is skewed, and unfair to both systems. Human labels on each step of answer generation would be best, but they take domain experts’ time on boring work.

Two questions I keep open

What does RAG look like beyond a chatbot? And how do you make subjective LLM evals quantitative and understandable? If you are working on either, I would like to hear how.
